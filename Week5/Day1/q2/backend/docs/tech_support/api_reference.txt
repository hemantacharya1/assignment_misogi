Document: How to Use Our API for Authentication
To start using our API, you’ll need to authenticate your requests using an API key. You can find your unique API key by logging into your dashboard, navigating to the API Keys section, and clicking Generate Key. Keep this key secure—treat it like a password.

Include this key in the Authorization header of each request. For example:

makefile
Copy
Edit
Authorization: Bearer YOUR_API_KEY
If your requests return a 401 Unauthorized error, double-check that your key is active and correctly copied. Also, ensure your account hasn’t hit its usage limit.

If you need to rotate your key for security reasons, simply revoke the current key and generate a new one in the dashboard. Your API integrations will need to be updated with the new key right away.

Document: Troubleshooting 500 Errors in the API
A 500 error means something unexpected happened on our end. While it’s not always something you can fix directly, there are a few steps you can take to help us resolve it faster.

First, check your request payload. Common causes of 500 errors include malformed JSON or unexpected data types. Use a tool like Postman or curl to test the same request and confirm that the format is correct.

Second, review our API status page to see if there’s a known issue affecting your request. We post real-time updates there during any outages or incidents.

Finally, if you still need help, contact support with the full request details: endpoint, method, timestamp, and any response body received. This helps our engineering team troubleshoot more efficiently.
